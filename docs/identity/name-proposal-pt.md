## Sumário Executivo

Este documento propõe formalmente o nome **MANACÁ** para o Large Language Model (LLM) desenvolvido do zero para o Português do Brasil no âmbito da cooperação científica LNCC × NII/LLM-jp. A proposta segue os objetivos dessa cooperação.

**MANACÁ reúne três ativos inéditos:**

1. **Disponibilidade confirmada** — nenhum modelo, produto ou empresa de IA utiliza este nome (verificação em Hugging Face, GitHub, arXiv, INPI)
2. **Fonologia japonesa nativa** — マナカ (manaka) significa "verdadeiro centro" em japonês, criando uma ponte cultural bilateral sem precedentes
3. **Carga simbólica científica** — a *Tibouchina mutabilis* é a espécie da flora brasileira que mais precisamente representa um LLM em treinamento contínuo

## O Manacá-da-Serra: Fundamento Botânico

O manacá-da-serra (*Tibouchina mutabilis* (Vell.) Cogn., família Melastomataceae) é uma espécie **endêmica da Mata Atlântica** brasileira com uma propriedade singular documentada na literatura científica: suas flores mudam progressivamente de cor — **branco → rosa-lilás → púrpura** — com todos os estágios coexistindo simultaneamente na mesma árvore.

Este fenômeno, descrito na literatura como *sequential color change* (SCC), foi estudado por Weiss (1991, *Nature* 354:227–229) como um sistema de **sinalização dinâmica adaptativa**: as flores mais velhas (púrpura) são mantidas na planta mesmo após a fecundação porque aumentam a atratividade visual do conjunto, orientando os polinizadores para as flores jovens (brancas) ainda disponíveis.

```
Flor branca (jovem)     →   Flor rosa-lilás (adulta)   →   Flor púrpura (madura)
  Pré-treinamento       →      Fine-tuning              →      Alinhamento
  (absorção do corpus)  →   (instrução e tarefa)        →   (preferências humanas)
```

A **coexistência simultânea** dos três estágios na mesma árvore — a propriedade central da espécie — é a analogia estruturalmente mais precisa disponível na natureza brasileira para um LLM: múltiplas capacidades (linguagem geral, domínio especializado, seguimento de instruções) coexistindo em um mesmo modelo.

**Referências botânicas primárias:**
- Cogniaux, A. (1891). Melastomataceae. *Flora Brasiliensis*, vol. 14, part 3. Lipsiae: F. Fleischer.
- Weiss, M.R. (1991). Floral colour changes as cues for pollinators. *Nature*, 354(6350), 227–229. DOI: 10.1038/354227a0.
- Flora do Brasil 2020. Jardim Botânico do Rio de Janeiro. floradobrasil.jbrj.gov.br.
